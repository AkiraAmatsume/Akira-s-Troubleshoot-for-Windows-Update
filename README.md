# Akira's Troubleshoot for Windows Update

一个用于修复 Windows 更新组件损坏的第三方工具。

适用于 Windows 10、Windows 11（64 位）。

* * *

## 它能做什么

当系统被精简、优化或「禁用更新」类工具改动后，Windows 更新常会出现问题。本工具可以检测并自动修复以下情况：

* 更新设置页被隐藏或禁用
* 更新相关服务被禁用
* 更新服务未配置失败自动恢复
* 核心更新组件文件被删除或改名
* 更新缓存损坏
* 更新计划任务被禁用
* 「设置」应用无法正常打开

此外还会检查系统版本是否受支持、Windows 是否已激活（这两项只做提示，不自动修改）。

## 运行要求

* Windows 10 / Windows 11（64 位）
* .NET Framework 4.8（Windows 10 1903 及以上、Windows 11 已内置）
* 管理员权限（点击「开始检测」时会弹出 UAC，请选择「是」）

无需安装。直接运行 `Akira's Troubleshoot for Windows Update.exe` 即可。分发包中只包含这一个 exe 文件，不附带额外的资源文件（语言资源由系统自带的 .NET Framework 提供，见下文「语言资源」）。

## 怎么用

1. 双击运行程序，进入欢迎页。
2. 点击「开始检测」，在 UAC 提示中选择「是」以授予管理员权限。
3. 程序自动检测各项问题，并显示进度与结果。
  * 若全部正常，页面只会显示「关闭」，无需修复。
4. 若检测到可修复的问题，点击「开始修复」。
5. 等待修复完成后，按提示**重启电脑**，使更改完全生效。

程序在开始检测前会先把将被修改的注册表项备份到**桌面**上的`WU_Restore_Backup_时间戳\` 文件夹（4 个 `.reg` 文件）。需要还原时，双击导入对应文件即可。

## 需要注意

* 修复后建议重启电脑，部分改动（服务、DLL 注册、缓存）需重启后才完全生效。
* 「系统兼容性」和「系统激活」两项只做提示，不自动修改。
* 本工具**不会**改动你的网络代理设置。
* 若完成页出现「需要手动处理」，通常是因为系统未激活，或组件存储本身已损坏；后者建议使用与当前系统版本一致的 Windows ISO 执行就地升级修复。

## 常见问题

**双击后没有出现 UAC 提示？** 

正常现象。程序以普通权限启动，只有点击「开始检测」后才会请求管理员权限。

**检测说文件缺失，但我没有删过文件？** 

多半是某些精简工具把组件文件改名（`*_BAK.dll`）或删除了。工具会尝试恢复。若文件确实完好却仍报缺失，请附上系统版本信息反馈。

**修复后没生效？** 

请先重启电脑。

**部分项目显示「需要手动处理」？** 

例如系统未激活，或组件存储中找不到可恢复的源文件。前者请自行激活；后者建议使用 Windows ISO 执行就地升级。

**兼容性一项显示「未验证兼容性」或「系统不受支持」？** 

当前系统不在 Windows 10 / 11 范围内（如 Windows Server 或更早版本）。检测结果仍会显示，但自动修复可能不适用，请谨慎使用。

## 语言资源

本工具自身的界面文字（按钮、提示、检测结果等）已直接写入程序，不依赖任何外部语言文件。分发包中不包含语言资源文件，原因如下：

* .NET Framework 4.8 自带简体中文资源，位于系统目录`C:\Windows\Microsoft.NET\Framework\v4.0.30319\zh-Hans\`。中文版 Windows 10 / 11 均已内置，程序运行时会自动使用，无需另行提供。
* 因此单独附带一份语言资源既无必要，也会增大分发包体积。

说明：若在英文版 Windows 上运行，仅 .NET 框架自身的少数底层提示可能显示为英文，本工具界面与检测、修复结果仍为中文，不影响使用。
